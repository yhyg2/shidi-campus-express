# 管理后台

后台包含概览、订单、成员、代取、定价、公告、设置七个页面。普通用户无管理权限；管理员可处理运营数据；超级管理员具有全部权限，且不能被普通管理员移除。

## 首次进入

本地演示可以直接使用演示角色或初始化入口。云端必须先完成 [部署说明](导入与部署.md) 中的指定账号初始化。初始化完成后，为其他管理员生成一次性成员邀请码。

## 日常操作

- **订单**：筛选状态、指派同校区代取、取消未结束订单、导出当前筛选结果。导出包含联系方式与地址，只能保存在受控位置，不要上传到代码仓库。
- **投诉**：查看投诉并填写处理说明。处理后允许用户就新的问题再次发起投诉。
- **代取**：生成绑定校区的邀请，按姓名和学号人工核验。证件图片目前不在后台提供独立预览；不要在未完善审核流程时启用必传证件照。
- **定价**：按件或按单计费，可设置尺寸、时段、上下限；金额在服务端以分计算。距离计费暂不可启用。
- **公告**：新增、编辑、置顶或下线。公开返回的公告不含发布者身份标识。
- **设置**：配置校区、驿站、楼栋、客服、取件时段、邀请码有效期与接单容量。默认名称均为演示样例。

## 限制

订单、成员和日志列表有数量上限，尚无完整分页；不要把概览和 CSV 当作无遗漏的运营台账。没有唯一超管转移界面、支付、结算、账号删除或图像审核。禁止通过公开问题区交换邀请码、用户资料或云控制台截图。
