# shidi-campus-express · 校园快递代取微信小程序

**第一次使用请先看：[说明文档](说明文档.md)**，包含运行、云端部署、管理员初始化、版本改动及验证范围。

A WeChat Mini Program for campus parcel pickup and delivery, with student orders, runner workflows, admin tools, and a local demo.

基于微信小程序与云开发的校园快递代取项目。普通用户可以下单，经邀请与管理员审核后可接单；管理员在小程序内管理订单、成员、定价、公告和运营配置。

当前版本：**3.1.0，早期公开版本**。提供本地演示与云函数实现；费用线下结算，没有接入微信支付。仓库默认使用虚构的校区、驿站和账号样例。

## 快速开始

本地检查需要 Node.js 22 或 24，不需要安装根目录依赖。

```bash
npm test
npm run check
npm run release:check
```

使用微信开发者工具导入**项目根目录**，后端选择小程序项目。默认 AppID 为通用占位值 `touristappid`，`miniprogram/config.js` 的云环境留空，进入的是本机演示模式。工具不支持游客导入时，改用自己的测试 AppID；不要提交该改动。

本地演示中的角色切换只用于界面体验，不能改变云端权限。演示数据不与其他设备共享。

云端部署、数据库及存储权限、首个管理员的安全初始化见 [部署说明](docs/导入与部署.md)。

## 已有功能

| 范围 | 功能 |
| --- | --- |
| 学生端 | 报价、下单、查看订单、取消未取件订单、确认收货、评价与投诉 |
| 代取端 | 邀请码认证、审核状态、上线/休息、同校区接单、取件/送达状态更新 |
| 管理端 | 订单与投诉处理、人工指派、成员邀请、代取审核、定价、公告、校区和客服配置、CSV 导出 |
| 订单隐私 | 完整订单仅下单人、该单代取和管理员可读；分享只返回摘要；大厅隐藏完整交接位置 |
| 安全控制 | 微信上下文身份、服务端权限校验、初始化账号限制、事务接单、一次性邀请、账号限速、CSV 公式防护 |
| 开发支持 | 共享纯函数核心、模拟云端回归测试、配置一致性和公开发布检查 |

取件码当前采用 **2-1-4 位**，例如 `12-3-4567`。接单容量配置范围为 1–10。订单号采用时间戳与随机串，不是连续自增号码。

## 目录

```text
shidi-campus-express/
├── miniprogram/          小程序页面、组件、样式与本地演示
├── cloudfunctions/api/   云函数、服务端安全校验、依赖锁文件
├── shared/core.js        共享业务核心
├── tests/                核心、本地流程及模拟云端测试
├── scripts/              同步、语法检查与公开发布检查
├── docs/                 部署、权限、验证与维护说明
├── preview/              虚构内容的静态界面预览
└── .github/              持续集成、问题模板与依赖更新配置
```

修改 `shared/core.js` 后运行 `npm run sync`，再执行测试。不要只修改小程序或云函数中的核心副本。

## 使用边界

- 未完成真实微信云环境、真机和多设备联调；本地模拟测试不证明生产部署可用。
- 订阅消息模板默认留空，需部署者申请并配置模板及对应字段。
- 没有支付/结算、批量接单、送达照片凭证、宿舍性别匹配、连续自增订单号、图片内容审核或自动资料删除。
- 未接定位、导航和可信距离来源，界面禁用距离计费与距离派单。
- 列表有数量上限，未实现完整分页，统计与导出不能当作完整财务台账。
- 用户协议和隐私政策为部署参考文本，运营者须补充运营身份、联系方式、保留期限和删除流程，并按实际服务配置平台隐私指引。
- 微信平台资质、服务类目、审核与云服务价格以官方控制台的当前规则为准。
